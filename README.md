# Games But No Games

A RuneLite plugin project for playing small, standalone mini-games while waiting.

Games include Snake, Minesweeper, and Tunnel Flight. All games run entirely in the plugin panel and do not automate RuneScape, read game state for an advantage, or send input to the game.

## Development

This project targets Java 11 and uses the RuneLite example-plugin development setup. 

*AI used in the making of this plugin.
